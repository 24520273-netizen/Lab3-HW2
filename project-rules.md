Lab 03 Homework 2 - Project Rules
=================================

Stack: React 19, Vite, JavaScript, CSS Modules, Web Audio API.

1. Plan -> Implement -> Verify -> Commit.
2. Keep changes scoped to the HW2 repository.
3. Use React functional components, createRoot and StrictMode.
4. Do not use class components, ReactDOM.render, defaultProps, keyCode or window.alert.
5. Do not mutate React state or add redundant effects.
6. Use semantic HTML, keyboard accessibility and responsive layouts.
7. Target WCAG 2.2 AA and Lighthouse Accessibility 100.
8. Use React.memo for PianoKey and stable props/callback references.
9. Use one managed AudioContext and at most eight active voices.
10. Clean up oscillators, nodes, timers and asynchronous operations.
11. Validate lint, build and relevant functional tests before committing.
12. Do not commit generated build output, dependencies or secrets.
13. Preserve any lecturer-required commit names.
14. Do not push, merge, reset or rebase without an explicit request.
15. Record at least three evidence-backed AI failures in the final audit.
